# Smart Diabetes Prediction System

A Flask-based web application designed to collect basic patient information, diabetes-related symptoms, and glucose levels to provide a simple computer-generated diabetes estimation.

## Features

- Patient name and age input
- Diabetes symptom collection
- Glucose level input
- Symptom-based insulin estimation
- Diabetes status estimation based on glucose level
- Patient result report
- Simple and user-friendly web interface
- Flask backend with HTML templates
- Custom background images and styling

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
